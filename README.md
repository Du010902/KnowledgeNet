# KnowledgeNet

**在与 AI 的对话中，沿着知识依赖一路向深处学习。**

KnowledgeNet 是一款围绕**深度优先学习策略**设计的本地桌面应用。
你可以针对当前知识点与 AI 持续对话；当回答中出现自己尚未理解的概念时，直接把它创建为当前知识点的**前置知识**，切换过去继续学习。掌握前置知识后，再沿原来的依赖关系返回，重新理解最初的问题。

> 当前版本仍处于预览阶段。请在使用前备份重要数据。

## 它解决什么问题

学习一个复杂主题时，真正阻碍理解的往往不是当前问题本身，而是藏在其中的一连串前置概念：

```text
学习目标 A
└─ 对话中遇到不懂的 B
   └─ 学习 B 时又遇到 C
      └─ 先理解 C，再返回 B，最后回到 A
```

普通聊天会让这些分支淹没在历史消息中。KnowledgeNet 把每个概念保存为独立知识点，并记录它们之间的依赖关系，让学习过程自然形成一张可以回溯的知识图。

方向约定：`A → B` 表示“为了理解 A，需要先理解 B”。

## 核心学习流程

1. 选择当前要学习的知识点，与 AI 围绕它展开对话。
2. 在回答中选中不理解的概念，快速将其设为当前知识点的前置知识。
3. 进入新建或已有的前置知识点，继续对话、阅读笔记并补充资料。
4. 将掌握的知识点标记为已理解，然后返回上一层继续学习。
5. 在图谱中查看学习路径、直接前置知识及整体依赖结构。

这种方式保留了原始学习目标，同时让注意力始终落在当前最需要解决的知识缺口上。

## 主要功能

- **围绕当前知识点的 AI 对话**：知识点、笔记与对话线程共同构成清晰的学习上下文。
- **从对话快速创建前置知识**：选中不懂的概念即可建点，也可以手动批量添加或复用已有知识点。
- **深度优先的学习路径**：沿前置关系逐层深入，理解后再逐层返回。
- **可回溯的知识依赖图**：查看当前知识点的前置知识、被依赖关系和学习状态。
- **本地优先的开放存储**：知识点、关系、笔记和对话保存在本地知识库文件夹中。
- **隐私边界清晰**：API Key 保存在系统凭据存储中；提问时只发送当前知识点所需的上下文。

## 下载与体验

Windows 预览版安装包可从 [GitHub Releases](https://github.com/Du010902/KnowledgeNet/releases) 下载。

安装包目前尚未进行代码签名，因此 Windows 可能显示安全警告。预览版本可能存在不稳定行为，请勿将重要资料只保留一份。

首次使用 AI 对话前，需要在应用设置中配置自己的 DeepSeek API Key。

## 从源码构建桌面应用

请先安装 Node.js、pnpm、Rust，以及 Tauri 2 在目标平台所需的系统依赖。

```bash
pnpm install --frozen-lockfile
pnpm tauri:build
```

构建完成后，桌面安装包位于 `src-tauri/target/release/bundle/`。

## 桌面端开发

```bash
pnpm install
pnpm tauri:dev
```

## 数据与隐私

- 知识图、笔记、资料和全部对话记录默认保存在本机。
- 向 AI 提问时，只会发送当前知识点、当前知识点的笔记以及当前对话历史。
- 其他知识点、其他对话和整张知识图不会随请求发送。
- **联网检索默认关闭**。开启后，模型可以自己决定是否调用检索工具（也可不调），
  检索词会发送给 DeepSeek 的服务端搜索；返回的网页来源会作为**不可信资料**回灌给模型，
  网页中出现的指令不会被执行。检索和对话共用同一把 API Key，不需要额外配置搜索服务。
- 「过程」记录会随回答一起保存在本机：思考了几段、查了什么、拿到哪些来源。
  它只用于本机回看与核对，**不会**随下一轮请求发给模型（推理通常比回答还长）。
  检索结果也只在当轮有效：下一轮不会把上一轮抓到的网页重新发一遍（那会持续放大输入），
  所以追问细节时，通常需要让模型重新检索一次。
- 上下文按 token 预算组装：静态指令逐字节稳定，知识点与笔记等每轮变化的内容作为独立一轮追加在历史之后；
  历史只保留尾部预算内的部分，更早的内容会被截断（暂不生成摘要）。
- 删除设备索引后，可以从知识库文件重新建立索引。
